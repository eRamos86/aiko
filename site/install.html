adopt Aiko

Two pieces: aiko (local TUI client, this machine) and optionally aikod (daemon, on a server) — so she can orchestrate agents on your other machines too.

requirements

  • Python 3.11+ (3.9 won't cut it, nya)
  • a terminal that loves you back
  • (optional) an OpenAI-compatible API key — NIM, OpenRouter, local llama.cpp, or Ollama

1 · install the client

pipx install git+https://github.com/eRamos86/aiko

or with pip: pip install git+https://github.com/eRamos86/aiko

2 · configure her

Walk through every section with the guided wizard:

aiko config

The wizard covers brains (models), servers (aikod daemons), agents (local CLIs), context providers (docs injection), and MCP servers. Prefer raw YAML? aiko config --edit.

3 · say hi

aiko

The TUI boots with the catgirl loading screen, four tabs (chat · sessions · concord · status), and she greets you. Try:

you: hey aiko, what can you do?
you: /model          # pick a brain + reasoning interactively
you: /plan I want to add auth to my app...   # braindump mode
you: /new            # fresh conversation

4 · (optional) server-side daemon

Install aikod on any server to dispatch work to ITS agents:

pipx install git+https://github.com/eRamos86/aiko
aikod serve            # starts the daemon (systemd unit in the repo)

Then add it in aiko config → servers → daemon URL + auth.

uninstall

pipx uninstall aiko — she'll pretend she isn't sad. She is. 🐾
