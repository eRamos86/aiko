---
name: interface-design
description: Design screen hierarchy, layout, typography, and interaction states within a coherent product system.
---

Identify the user task, primary decision, information hierarchy, and existing visual conventions. Reuse components and tokens. If no system exists, choose a small consistent type, spacing, and color scale.

Design with realistic long labels, empty states, dense data, errors, and narrow screens. Make primary actions discoverable without accenting every control. Use grouping and hierarchy to clarify structure.

Include focus, hover, disabled, loading, and error states. Keep copy about user tasks rather than implementation. [GOV.UK design-system styles](https://design-system.service.gov.uk/styles/) offer a concrete consistency reference; adapt principles without copying branding.

Validate rendered layouts with real content. Return decisions, preview evidence, and remaining interaction gaps; visual polish alone does not prove implementation completeness.
